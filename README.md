### Featured Projects

#### 1. SEAL Data Lakehouse Architecture
*Lightweight Medallion architecture designed to consolidate multi-system field assessments into an auditable analytical foundation.*

* **Problem:** Fragmented spreadsheet workflows and disparate collection tools led to data drift, unvalidated coordinates, duplicate records, and irreproducible operational reporting.
* **Architecture & Approach:** Built a localized Medallion lakehouse (Delta Lake + DuckDB) orchestrated via Prefect and Python. Engineered persisted layer boundaries, automated KoboToolbox API ingestion, surrogate key generation, and referential-integrity quarantine tables.
* **Impact:** Enabled reproducible analytical reporting across **981 schools, 27 districts, 193 supervisors, and 200,000+ beneficiaries** without enterprise database server overhead.
* **Stack:** ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Delta Lake](https://img.shields.io/badge/Delta_Lake-003366?style=flat-square) ![DuckDB](https://img.shields.io/badge/DuckDB-FFF000?style=flat-square&logo=duckdb&logoColor=black) ![Prefect](https://img.shields.io/badge/Prefect-070707?style=flat-square) ![Power BI](https://img.shields.io/badge/Power_BI-F2C811?style=flat-square&logo=powerbi&logoColor=black)

#### 2. Enterprise Sales Data Warehouse (PostgreSQL)
*Scalable ELT pipeline and dimensional warehouse built to unlock historical sales trends from legacy transactional systems.*

* **Problem:** Multi-year transaction records were siloed across legacy SQL Server instances, hindering historical analysis and risking production transactional contention.
* **Architecture & Approach:** Architected a modular PostgreSQL data warehouse using Kimball dimensional modeling (Star Schema). Automated multi-batch extraction, semantic field mapping, and financial metric standardization.
* **Impact:** Unified **18,000+ sales facts** and enriched **22,000+ catalog items** across **54+ relational entities**, backed by 14 automated data-integrity test suites.

#### 3. Geospatial GPS Imputation Pipeline
*Automated spatial error-detection and imputation framework for field survey datasets.*

* **Problem:** Field-collected GPS records contained default fallbacks, high-imprecision markers, and dropped coordinates, impairing spatial dashboards and coverage tracking.
* **Architecture & Approach:** Designed a 3-tier cascade fallback mechanism combining historical asset coordinate matching with distance-weighted K-Nearest Neighbors (KNN, $k=5$) via Haversine metrics.
* **Impact:** Imputed ~1,600 invalid records with a **20.6% error reduction** over baseline configurations (1.055 km mean accuracy), cutting manual validation effort by **>70%**.
* **Stack:** ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Scikit-Learn](https://img.shields.io/badge/Scikit--Learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white) ![GIS](https://img.shields.io/badge/GIS-Haversine-green?style=flat-square)

#### 4. Multilingual Entity Transliteration (Arabic to English)
*Hybrid NLP engine designed to standardize geographic and administrative nomenclature for GIS joining.*

* **Problem:** Orthographic and dialect variations in Arabic administrative names caused systematic join failures across GIS datasets and cross-organizational reporting.
* **Architecture & Approach:** Built a two-stage pipeline combining deterministic regex normalization with a Seq2Seq LSTM network (Bahdanau Attention) for complex phonetic translations, supported by confidence scoring for human-in-the-loop review.
* **Impact:** Trained on **81,000+ name pairs** and evaluated against a benchmark of **12,000+ regional records**, standardizing master administrative records for downstream joins.
* **Stack:** ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white) ![Keras](https://img.shields.io/badge/Keras-D00000?style=flat-square&logo=keras&logoColor=white)
